Brass Pulse KFK

An iOS metronome for irregular measures, changing time signatures, custom groupings, loops, and practical rehearsal work.

iPhone and iPad Irregular meters Local song library No tracking

What It Does

Build measure sequences

Create songs with changing time signatures, consecutive displayed measure numbers, and per-measure grouping presets.

Practice with focus

Start playback from any measure, add an optional 4/4 count-in, and loop a selected range while the active measure stays highlighted.

Keep your setup

Songs, tempo, loop settings, count-in choice, and measure sequences are saved locally on your device.

Manual

Play and stop

  1. Use the play button to start the current song from the selected measure.
  2. Tap a measure card to begin playback from that measure.
  3. Use pause to stop playback and clear the active playback highlight.

Set tempo

  1. Move the BPM slider for direct tempo changes.
  2. Tap the tempo button repeatedly to calculate a tap tempo.
  3. Changing BPM during playback stops the current run so the next start uses the new tempo cleanly.

Edit songs and measures

  1. Create, duplicate, rename, delete, or select songs from the song controls.
  2. Set the first displayed measure number; later measures number themselves consecutively.
  3. Insert a measure at a sequence boundary, adjust its numerator and denominator, then choose a grouping such as 2+2+3 for 7/8.
  4. Delete a measure when the song has more than one measure.

Use loops

  1. Enable the loop range control.
  2. Choose inclusive start and end measure numbers.
  3. Playback wraps inside that range and shows the current loop count.

Built-in songs

Built-in material can be played immediately. Tempo, count-in, and loop settings remain adjustable. Composition edits are locked unless you duplicate the song or temporarily unlock an edit control with a long press.
